Site rules

Patterns
  • example.com — this domain and its subdomains
  • *.example.com — same domain and subdomain behaviour
  • example.com/path — this case-sensitive path and everything under it

Blacklist

All visual content stays blurred on these sites, whatever the text analysis says.

Note — the blacklist wins. A site on both lists is blacklisted.

Protection

Videos, maps, posts and ads are often embedded from another site, and PhobiaBlocker can't reliably see inside them.

On, embeds stay blurred until you reveal them. Off, they appear once the rest of the page looks safe — but they could still hold something you asked to hide.

How it works

Overview

PhobiaBlocker blurs images, videos and embeds on pages that may contain triggers for your specific phobias. It reads the page's text to decide what to hide.

If any of your trigger words appear anywhere on a page, all visual content on that page stays blurred.

  1. Blur everything as the page loads
  2. Search the text for your trigger words
  3. Remove the blur only if nothing is found

Word matching

Matching uses the compromise NLP library, so word variations are covered:

  • Plurals — "cat" matches "cats"
  • Verb forms — "rise" matches "rose", "risen"
  • Irregular plurals — "mouse" matches "mice"
  • Possessives — "spider" matches "spider's"
  • Any case — "SPIDER", "Spider" and "spider" all match

Fail-safe design

The order matters: content is hidden first and revealed only after analysis clears it.

  • CSS blur first — applied as the page loads, before any script runs
  • Then analysis — the text is checked against your words
  • Errors keep the blur — if anything fails, content stays hidden

What gets blurred

  • Images — <img> including GIFs
  • Background images — any CSS background-image
  • Videos — <video> elements
  • Embeds — <iframe> such as YouTube or Vimeo

Dynamic pages

New content from infinite scroll or single-page apps is picked up automatically and blurred as it arrives.

Debug mode

For troubleshooting only. Writes verbose logs to the console.

Logs cover
  • Text analysis — word matching and normalisation results
  • Media detection — images, videos, embeds and their blur state
  • DOM changes detected and processed
  • Settings loaded and saved
  • Messages between extension components

Open developer tools (F12, or Cmd+Option+I on a Mac) and use the console tab.
